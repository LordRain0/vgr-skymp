      Gamemode
      
          
      …
      
          Merges vgr-gamemode/ (loader + extensions) onto the live server. Never deletes server-only files; overwritten ones are backed up. Restart the Game service afterwards - extensions load once at startup.
          
      
            
            
          
      
        
      
        
      
          
      Game server
      
          Bundles the TypeScript (skymp5-server) and deploys dist_back/skymp5-server.js to the live server (previous bundle backed up). Restart the Game service to run it. scam_native.node comes from the CI PR Windows Flatrim artifacts.
          
        
      
        
      
          
      Launcher
      
          
      
            
            
      
              
              
            
      
          
      
          Writes package.json, LAUNCHER_LATEST_VERSION in .env, and routes/version.js. Restart the Backend to serve it.
          
        
      
        
      
          
      Client files
      
          
      …
      
          Rebuilds skymp5-client.js into the CI payload at build/dist/client, overlays vgr-frontend, and packages skymp-client.zip + files-version.json. Mind the CLIENT_ZIP_URL warning in the log.
